# KernelSocket-API — окружение для тестовых драйверов Windows

Данный модуль предоставляет удобный способ восстановления NuGet-пакетов, используемых тестовыми драйверами под Windows.

## Требования

| Компонент | Назначение |
|----------|-----------|
| Visual Studio 2022 | Среда разработки |
| WDK (Windows Driver Kit) | Набор инструментов для разработки драйверов |
| MSVC C++ libraries (Spectre-mitigated) | Библиотеки с защитой от уязвимостей Spectre |

Установка выполняется через **Visual Studio Installer** → вкладка **«Отдельные компоненты»**.

## Как это работает?

В корневой директории проекта расположен файл `Directory.Build.Props`, который задаёт пути ко всем зависимостям, используемым драйверами. Благодаря этому при создании нового тестового драйвера разработчику не требуется вручную настраивать зависимости — они подключаются автоматически.

Пример ключевых строк, определяющих расположение NuGet-пакетов:

```xml
<Import Project="$(PackagesDir)microsoft.windows.sdk.cpp/10.0.26100.7705/..." Condition="..." />
<Import Project="$(PackagesDir)microsoft.windows.sdk.cpp.x64/10.0.26100.7705/..." Condition="..." />
<Import Project="$(PackagesDir)microsoft.windows.wdk.x64/10.0.26100.6584/..." Condition="..." />
```

## Восстановление пакетов

Для восстановления всех зависимостей выполните следующую команду:

```bash
dotnet restore restore-packages/RestorePackages.csproj
```

В результате все необходимые NuGet-пакеты будут установлены в директорию `packages/`, расположенную в корне проекта.


## Дальнейшая настройка проекта
После этого разработчик может создавать собственные тестовые драйверы без необходимости дополнительного управления пакетами.

Если в процессе работы возникают ошибки, обратитесь к документу [Настройка проекта под Windows](../docs/build-docs/windows-build.md), где описаны основные этапы сборки и приведены типичные проблемы и способы их решения.

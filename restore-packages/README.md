# KernelSocket-API — восстановление всех зависимостей для Windows

Данный модуль предоставляет удобный способ восстановления NuGet-пакетов, которые используются для компиляции `.lib` файла для подключения к проекту, а также для работы всех туториалов и тестовых драйверов под Windows.

## Требования

| Компонент | Назначение |
|----------|-----------|
| Visual Studio 2022 | Среда разработки |
| WDK (Windows Driver Kit) | Набор инструментов для разработки драйверов |
| MSVC C++ libraries (Spectre-mitigated) | Библиотеки с защитой от уязвимостей Spectre |
| .NET SDK 10.0 | Набор инструментов от Microsoft |


Установка выполняется через **Visual Studio Installer** → вкладка **«Отдельные компоненты»**. При этом .NET SDK 10.0 рекомендуется скачать внешним установщиком с официального сайта Microsoft.

## Как это работает?

В корневой директории проекта расположен файл `Directory.Build.Props`, который задаёт пути ко всем зависимостям, используемым драйверами. Благодаря этому при создании нового тестового драйвера разработчику не требуется вручную настраивать зависимости — они подключаются автоматически, в том числе и к модулю компиляции `.lib` файла.

Пример ключевых строк, определяющих расположение NuGet-пакетов:

```xml
<Import Project="$(PackagesDir)microsoft.windows.sdk.cpp/10.0.26100.7705/..." Condition="..." />
<Import Project="$(PackagesDir)microsoft.windows.sdk.cpp.x64/10.0.26100.7705/..." Condition="..." />
<Import Project="$(PackagesDir)microsoft.windows.wdk.x64/10.0.26100.6584/..." Condition="..." />
```

## Восстановление пакетов

Для восстановления всех зависимостей в любом удобном терминале, находясь в корне проекта, выполните следующую команду:

```bash
dotnet restore restore-packages/RestorePackages.csproj
```

В результате все необходимые NuGet-пакеты будут установлены в директорию `packages/`, расположенную в корне проекта.

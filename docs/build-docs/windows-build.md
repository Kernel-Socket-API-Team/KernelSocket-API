# Использование и сборка библиотеки под Windows

## Для кого этот документ

Данная инструкция предназначена для разработчиков, которые хотят собрать библиотеку из исходного кода или разобраться в архитектуре сборки.  
Рядовым пользователям достаточно готовой библиотеки (`.lib`) и заголовочного файла из папки `bin`.

---

## Требования

| Компонент | Назначение |
|-----------|------------|
| Visual Studio 2022 | Среда разработки |
| WDK (Windows Driver Kit) | Набор инструментов для разработки драйверов |
| MSVC C++ libraries (Spectre-mitigated) | Библиотеки с устранением рисков Spectre |

Установка выполняется через **Visual Studio Installer** → вкладка **"Отдельные компоненты"**.

---

## Сборка библиотеки

### 1. Открытие решения

Откройте файл `compileLibraryForWindows.slnx`, расположенный в папке `compileLibraryForWindows/`.

### 2. Настройка под вашу версию WDK

В открытом решении настройте пути к WDK и SDK в соответствии с вашей версией.  
Пакеты находятся в папке `packages` на одном уровне с решением — пути к ним уже настроены, но могут потребовать корректировки в зависимости от версии.

### 3. Выбор конфигурации

Выберите нужную конфигурацию:
- **Debug** — для отладки
- **Release** — для финальной сборки

### 4. Компиляция

Выполните сборку решения (`Ctrl+Shift+B`).  
Результат — `.lib` файл, который появится в папке `bin`.

## Как это работает

### Платформозависимая компиляция

Диспетчер на этапе компиляции определяет целевую платформу с помощью макросов:

```c
// src/dispatcher/dispatcher.c

const net_vtable_dispatcher* vtable =
#ifdef _WIN32
    &windows_vtable;
#else
    &linux_vtable;
#endif
```

Linux-код при этом плоностью исключается из сборки под Windows, что упрощает зависимости и ускоряет компиляцию.

## Настройка проекта (для справки)

Если вы создаёте проект с нуля или хотите понять текущие настройки:

| Шаг | Действие |
|-----|----------|
| **Шаблон** | Создайте проект на основе **KMDF (empty)** |
| **Тип сборки** | Свойства проекта → Общие → Тип конфигурации → **Статическая библиотека (.lib)** |
| **WDK/SDK** | Пути к пакетам задаются через `<Import>` в `.vcxproj`. Пакеты находятся в папке `packages` на уровне решения |
| **Исходные файлы** | Файл `all_sources.c` содержит пути ко всем .c файлам библиотеки |

## Возможные проблемы

### Ошибка "ValidateNTTargetVersion"

**Симптом**:

```
Невозможно загрузить задачу "ValidateNTTargetVersion" из сборки...
```

**Причина**: Несоответствие версий WDK и ожидаемой версии Visual Studio.

**Решение**: В папке packages найдите файлы:

- `Microsoft.DriverKit.Build.Tasks.17.0.dll`
- `Microsoft.DriverKit.Build.Tasks.PackageVerifier.17.0.dll`

Скопируйте их и переименуйте, заменив 17 на требуемую версию (например, 18).

## Подключение библиотеки к вашему проекту

1. Добавьте путь к папке `include/` в разделе "Дополнительные каталоги включаемых файлов"

2. Добавьте соответсвующий `.lib` файл из папки `bin` в "Дополнительные зависимости" компоновщика

4. Так же в дополнительные зависимости, необходимо явно добавить `netio.lib` для корректной работы библиотеки.

Пример использования

```c
#include <ksockapi.h>

// ...
```

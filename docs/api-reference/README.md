Добро пожаловать в документацию **Kernel Socket API** — кроссплатформенной библиотеки для работы с сетевыми сокетами в среде ядра (Windows / Linux).

## Туториалы

Чтобы подчеркнуть кроссплатформенность библиотеки, все туториалы представлены в виде отдельных рабочих потоков. Код реализуется практически одинаково для обеих платформ, за исключением некоторых особенностей, которые будут отдельно отмечены.

### Список туториалов

#### [UDP-эхо сервер](./tutorials/udp-echo-server/udp-echo-server.md)

- Инициализация библиотеки
- Создание UDP-сокета
- Привязка к локальному адресу
- Приём дейтаграмм и отправка обратно отправителю
- Обработка ошибок

#### [TCP-сервер для одного клиента](./tutorials/tcp-server/tcp-server.md)

- Инициализация библиотеки
- Создание слушающего сокета
- Привязка к адресу и ожидание подключения
- Приём данных от клиента
- Отправка ответа и закрытие соединения

#### [TCP-клиент с IPv6](./tutorials/tcp-ipv6-client/tcp-ipv6-client.md)

- Инициализация библиотеки
- Парсинг IPv6-адреса (с портом и без)
- Создание и подключение сокета
- Отправка и приём данных
- Получение локального и удалённого адресов

#### [Функция диагностики сокета](./tutorials/log-function/log-function.md)

- Реализация комплексной функции `socket_diagnostic()`
- Получение типа сокета (`net_socket_get_type`)
- Получение протокола (`net_socket_get_protocol`)
- Получение локального и удалённого адресов (`net_socket_get_address`, `net_socket_get_remote_address`)
- Получение последней ошибки (`net_socket_last_error`)
- Получение платформозависимой ошибки (`net_socket_last_platform_error`)
- Формирование строкового отчёта о состоянии сокета

# Алгоритма поиска в ширину

Данный раздел описывает основные структуры данных, которые предоставляются пользователю для создания и настройки сокетов. Важно понимать эти структуры, так как правильно настроенный сокет во многом определяет поведение большинства функций.

## Обзор структур
```c
/* Коды ошибок API */
typedef enum {

    // Коды ошибок рассматриваются в другом разделе

} net_error_t;

/* Типы транспортных протоколов */
typedef enum {
    NET_PROTO_TCP = 1,  // TCP протокол
    NET_PROTO_UDP = 2   // UDP протокол
} net_protocol_t;

/* Семейства адресов (типы IP) */
typedef enum {
    NET_AF_INET4 = 4,   // IPv4
    NET_AF_INET6 = 6    // IPv6
} net_family_t;

/* Типы сокетов */
typedef enum {
    NET_SOCK_TYPE_TCP_LISTEN,      // Слушающий TCP сокет (сервер)
    NET_SOCK_TYPE_TCP_CONNECTION,  // Подключенный TCP сокет (клиент)
    NET_SOCK_TYPE_UDP              // UDP сокет
} net_socket_type_t;

typedef struct net_socket net_socket_t;

typedef struct net_address {
    net_family_t family;         // Семейство адресов (IPv4/IPv6)
    uint16_t port;               // Порт (в сетевом порядке байт)
    union {
        uint32_t ipv4;           // IPv4 адрес (в сетевом порядке)
        uint8_t ipv6[16];        // IPv6 адрес (в сетевом порядке)
    } addr;
    char hostname[256];          // Человекочитаемое имя (опционально)
} net_address_t;

#define NET_ADDRSTRLEN 54               // Максимальная длина строкового адреса
#define NET_WAIT_INFINITE ((size_t)-1)  // Бесконечное ожидание
```

## net_error_t

Тип, представляющий коды ошибок KernelSocket API. Используется как возвращаемое значение практически для всех функций библиотеки. Подробное описание всех кодов ошибок рассматривается в [данном разделе](./errors.md).

## net_protocol_t

Перечисление, определяющее транспортный протокол сокета. Может принимать одно из следующих значений:

* `NET_PROTO_TCP` — протокол TCP (Transmission Control Protocol), обеспечивающий надёжное соединение с установкой связи;
* `NET_PROTO_UDP` — протокол UDP (User Datagram Protocol), обеспечивающий передачу дейтаграмм без установки соединения.

## net_family_t

Перечисление, определяющее семейство адресов (тип IP-адреса). Используется для указания версии IP-протокола:

* `NET_AF_INET4` — IPv4, 32-битный адрес;
* `NET_AF_INET6` — IPv6, 128-битный адрес.

## net_socket_type_t

Перечисление, определяющее тип сокета в зависимости от его роли и протокола:

* `NET_SOCK_TYPE_TCP_LISTEN` — слушающий TCP-сокет, используемый на стороне сервера для ожидания входящих соединений;
* `NET_SOCK_TYPE_TCP_CONNECTION` — подключаемый TCP-сокет, используемый  клиентом, для установки соединения;
* `NET_SOCK_TYPE_UDP` — UDP-сокет, используемый для передачи дейтаграмм без установки соединения.

## net_socket_t

Непрозрачный тип, представляющий дескриптор сокета. Все операции с сокетом выполняются через указатель на эту структуру. Внутреннее устройство структуры скрыто от пользователя и доступно только через функции API.

## net_address_t

Структура, представляющая сетевой адрес сокета. Содержит следующие поля:

* `family` — Семейство адресов (`NET_AF_INET4` или `NET_AF_INET6`)
* `port` — Номер порта в сетевом порядке байт (network byte order)
* `addr` — Объединение (`union`), содержащее IPv4 или IPv6 адрес в сетевом порядке байт
* `scope_id` — Индекс сетевого интерфейса для IPv6 link-local адресов. Для IPv4 и глобальных IPv6 адресов должен быть равен 0. Обязателен для link-local адресов, иначе пакеты могут быть не доставлены.
* `hostname` — Опциональное человекочитаемое имя хоста (максимум 256 символов)

## Макросы (`#define`)

`NET_ADDRSTRLEN`

Макрос, определяющий максимальную длину строкового представления сетевого адреса. Значение равно 64 символам. Используется для выделения буфера при преобразовании адреса в строку.

`NET_WAIT_INFINITE`

Макрос, используемый для указания бесконечного времени ожидания в блокирующих операциях. Значение равно `((size_t)-1)`. Передача этого значения в функции ожидания означает, что операция будет блокировать выполнение до тех пор, пока не завершится успешно или не будет прервана.

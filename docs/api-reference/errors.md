# Коды ошибок

Данный раздел содержит полный справочник кодов ошибок, их значений и описание преобразования платформозависимых ошибок Windows и Linux в единые коды библиотеки.


## Обзор типов ошибок

Библиотека определяет следующие категории ошибок:

* **Ошибки инициализации** — связаны с регистрацией, активацией и состоянием библиотеки

* **Платформенные ошибки** — общие ошибки операционной системы (память, доступ, таймауты)

* **Ошибки работы с сокетами** — ошибки состояния сокета или протокола

## Коды ошибок

| Код | Значение | Описание |
|-----|----------|----------|
| `NET_ERROR_NOT_INITIALIZED` | 0 | Библиотека не инициализирована. Возникает при вызове функций API без предварительной успешной инициализации через `net_register()`/`net_activate()` |
| `NET_ERROR_NOT_REGISTER` | -1 | Библиотека не зарегистрирована. Вызов `net_register()` не был выполнен или завершился с ошибкой |
| `NET_ERROR_INVALID_VTABLE` | -2 | Некорректная виртуальная таблица. Внутренняя ошибка библиотеки, указывает на повреждение структур данных |
| `NET_SUCCESS` | -3 | Успешное выполнение операции. Операция завершена без ошибок |
| `NET_ERROR_NO_MEMORY` | -4 | Недостаточно памяти. Операционная система не смогла выделить требуемый объём памяти для сокета, буфера или внутренних структур |
| `NET_ERROR_ACCESS_DENIED` | -5 | Доступ запрещён. Операция не разрешена из-за недостаточных привилегий или ограничений безопасности |
| `NET_ERROR_TIMEOUT` | -6 | Превышено время ожидания. Операция не завершилась за отведённый интервал времени (например, подключение, приём данных) |
| `NET_ERROR_BUFFER_TOO_SMALL` | -7 | Размер буфера слишком мал. Переданный буфер недостаточен для размещения результата операции |
| `NET_ERROR_INVALID_PARAM` | -8 | Некорректный параметр. Один из переданных параметров имеет недопустимое значение (например, `NULL` указатель, некорректный размер) |
| `NET_ERROR_GENERIC` | -9 | Общая ошибка. Произошла непредвиденная ошибка, не подпадающая под другие категории |
| `NET_ERROR_INVALID_STATE` | -10 | Сокет в невалидном состоянии. Операция не может быть выполнена из-за текущего состояния сокета (например, отправка данных на закрытом сокете) |
| `NET_ERROR_INVALID_PROTOCOL` | -11 | Некорректный протокол. Запрошенный протокол не поддерживается или не соответствует типу сокета |

## Преобразование платформенных ошибок
Библиотека автоматически преобразует системные ошибки Windows и Linux в единые коды ошибок API. Это позволяет писать переносимый код без учёта платформенных особенностей.

### Windows → Kernel Socket API

## Преобразование Windows ошибок

Функция `convert_status_from_windows()` преобразует `NTSTATUS` в код ошибки библиотеки. Данная функция не доступна напрямую пользователю и вызывается внутри почти каждой функции, работающей с сокетом.

| NTSTATUS | Код Network API | Описание |
|----------|-----------------|----------|
| `STATUS_NO_MEMORY` | `NET_ERROR_NO_MEMORY` | Недостаточно памяти для выполнения операции |
| `STATUS_ACCESS_DENIED` | `NET_ERROR_ACCESS_DENIED` | Отсутствуют необходимые права доступа |
| `STATUS_TIMEOUT` | `NET_ERROR_TIMEOUT` | Превышено время ожидания операции |
| `STATUS_BUFFER_TOO_SMALL` | `NET_ERROR_BUFFER_TOO_SMALL` | Выходной буфер недостаточного размера |
| `STATUS_INVALID_PARAMETER` | `NET_ERROR_INVALID_PARAM` | Передан некорректный параметр |
| `STATUS_INVALID_HANDLE` | `NET_ERROR_INVALID_PARAM` | Передан некорректный дескриптор |
| `STATUS_SUCCESS` | `NET_SUCCESS` | Операция выполнена успешно |
| Другие | `NET_ERROR_GENERIC` | Неспецифицированная ошибка |

### Linux → Kernel Socket API

Функция `convert_status_from_linux()` преобразует коды ошибок `errno` (положительные значения, передаются как отрицательные) в коды ошибок библиотеки. Данная функция не доступна напрямую пользователю и вызывается внутри почти каждой функции, работающей с сокетом.

| errno | Код Network API | Описание |
|-------|-----------------|----------|
| `ENOMEM` | `NET_ERROR_NO_MEMORY` | Недостаточно памяти |
| `ENOBUFS` | `NET_ERROR_NO_MEMORY` | Недостаточно буферного пространства |
| `EACCES` | `NET_ERROR_ACCESS_DENIED` | Доступ запрещён |
| `EPERM` | `NET_ERROR_ACCESS_DENIED` | Операция не разрешена |
| `ETIMEDOUT` | `NET_ERROR_TIMEOUT` | Превышено время ожидания |
| `EINVAL` | `NET_ERROR_INVALID_PARAM` | Некорректный аргумент |
| `EMSGSIZE` | `NET_ERROR_BUFFER_TOO_SMALL` | Сообщение слишком велико для буфера |
| 0 (успех) | `NET_SUCCESS` | Операция выполнена успешно |
| Другие | `NET_ERROR_GENERIC` | Неспецифицированная ошибка |
